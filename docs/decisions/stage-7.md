# Stage 7 decision log: Review and report

- **The teacher's mark sits beside the AI's; it never replaces it.** `scores` keeps `ai_score`, the AI's reason and its key-point verdicts untouched, and adds `teacher_score`, `teacher_note`, `reviewed_by` and `reviewed_at`. The record then shows what the AI suggested, what the teacher decided and why, which is what the scoring study needs and what answers a student's "why did I get this mark?". Rejected: overwriting the AI score, which would destroy the evidence of how often the AI was wrong.
- **One function decides every final mark.** `reports/sheet.py` loads an exam once and applies one rule (the teacher's mark if set, otherwise the AI's; an unanswered question scores 0). The review page, the approval check, the Excel file and the PDF all read that same sheet, so they cannot disagree. Postgres stays the single source of truth: the report is rebuilt from it on every download, never stored as a separate copy.
- **The exam moves open -> closed -> approved, and marks can change only while it is closed.** Before closing, answers are still arriving; after approval, marks are locked so a downloaded report stays true. Approval is refused while any answer is unscored or flagged and not yet reviewed, and the refusal names them. Approving locks the exam row, and every review takes a shared lock on it, so an override cannot slip in during approval. A real browser run caught a gap here: "keep the AI's mark" on an answer the AI never marked had left it with no mark, and approval let it through. An answer with no final mark now always needs the teacher, and accepting a missing AI mark is refused.
- **Exports treat student text as untrusted.** openpyxl turns any string starting with "=" into a live formula, so every text cell is written as text, and an answer like `=HYPERLINK(...)` stays words. The PDF uses the built-in Latin-1 fonts, so curly quotes and the rupee sign are swapped for plain ones, and any other character becomes "?" rather than failing the export. That is enough for English answers; Telugu or Hindi answers (after Phase 3) would need a Unicode font bundled with the app.
- **Students do not see marks yet.** Whether students see their scores and feedback after approval is still an open question for faculty, so nothing about marks is exposed to the student role.
